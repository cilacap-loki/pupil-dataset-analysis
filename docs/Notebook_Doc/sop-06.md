# 📋 SOP-06: Generator Laporan PDF Diagnostik Klinis Individual

### 🎯 Tujuan
Menerbitkan dokumen **PDF Sertifikat Laporan Diagnostik Klinis Resmi** individual per-responden berbasis pustaka ReportLab.

### 📌 Langkah Operasional
1. Membaca metrik medis Hippus ($Mean\ D$, $Hz$, $\Delta D_{\%}$, $Amplitude$) dan berkas grafik dari SOP-05.
2. Menyusun tata letak dokumen (Kop Surat Akademik, Tabel Metrik Medis, Grafik Sinyal Temporal).
3. Merender berkas PDF `Laporan_Klinis_SOP06.pdf`.

### 📤 Luaran (*Output*)
* Berkas PDF resmi `Laporan_Klinis_SOP06.pdf` di folder `4_Hasil_Analisis_SOP06&07`.
