# 📋 SOP-09: Diseminasi & Manuskrip Scientific Jurnal

### 🎯 Tujuan
Mengintegrasikan seluruh artefak riset (sinyal temporal hippus, laporan klinis, dan validasi Ground Truth LPW) ke dalam naskah publikasi jurnal internasional bereputasi dan Laporan Akhir Hibah.

### 📌 Langkah Operasional
1. Menyusun abstrak, metodologi, dan pembahasan eksperimen.
2. Memasukkan tabel statistik Ground Truth LPW (SOP-07) dan grafik sinyal hippus (SOP-05).
3. Mengunggah naskah publikasi ke jurnal target.

### 📤 Luaran (*Output*)
* Draft Manuskrip Scientific Jurnal dan Laporan Akhir Hibah Riset.
